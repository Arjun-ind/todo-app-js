# 📝 Todo App

A simple and responsive Todo List application built using **HTML, CSS, and JavaScript**. It allows users to add, complete, delete, and manage daily tasks with data saved in the browser using Local Storage.

## 🚀 Live Demo

🔗 https://arjun-ind.github.io/todo-app-js/

## 📂 GitHub Repository

🔗 https://github.com/Arjun-ind/todo-app-js

---

## ✨ Features

- ✅ Add new tasks
- ✅ Mark tasks as completed
- ✅ Delete individual tasks
- ✅ Clear all tasks
- ✅ Press **Enter** to add a task
- ✅ Saves tasks using Local Storage
- ✅ Responsive design for desktop and mobile
- ✅ Task counter

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
